## Diagnostics
The app loads `diag.js`, which reports problems (script errors, taps on a control that changed nothing, taps something else caught) with the last 12 taps and screen details, never app data. Reports go to the `diag` collection in Med Med's Firestore, and an hourly Action in the med-med repo copies them to `med-med/data/diag/pk/`. When David reports a bug, read the newest files there first: `git -C ../med-med pull` (clone davidanthonyalleyne-dot/med-med if missing). To collect right away, change `data/diag/pull.txt` in med-med and push, then pull again a minute later. `diag.js` is the same file in every app; change it in all of them together.
